# Turbulent parameters archive

**TL;DR:** In this folder are different recompilations (VIENTO project and previous publications) of scaling relations and turbulent parameters in the context of interstellar medium, particularly H II regions.

# How this fits in the repo

The primary objective of the project VIENTO is recover the turbulent parameters of observed H II regions. Here we compile the project published results and the state-of-art related to turbulence in the interstellar medium.
